# System notes

Beleške o izmenama sistema na ovom laptopu: šta je promenjeno, zašto i kako se vraća. Pravila pisanja su u skillu `system-notes`; teme se nalaze po `##` naslovima (`grep -n '^## ' *.md`).

**Beleške se bave isključivo Ubuntuom.** Drugi operativni sistemi na ovoj mašini (dual-boot) ne pominju se, osim ako korisnik to izričito ne zatraži.

## Gde šta ide

- [macbook-setup.md](macbook-setup.md): sve izmene sistema koje se mogu vratiti (drajveri, boot, grafika, servisi, napajanje, hlađenje, uređaji, paketi, podešavanja Ubuntua), kritična pravila (ne diraj) i spisak uklonjenog. Ako ne pripada nijednom od ostalih fajlova, ide ovde.
- [extensions.md](extensions.md): naše GNOME ekstenzije.
- [claude-config.md](claude-config.md): izmene u `~/.claude` (hookovi, modovi, skillovi, permission pravila, pomoćne skripte).
- [analysis.md](analysis.md): merenja i popisi koji se mogu ponoviti, bez ičega za vraćanje.
- `files/<tema>/`: binarni fajlovi na koje upućuje beleška (npr. kalibracija kamere).
